# Java Console Calculator

Консольный калькулятор на **Java 21**: четыре арифметические операции,
десятичные числа, история вычислений и понятные сообщения об ошибках.
Учебный проект для практики Java Core, Maven, JUnit и GitHub Actions.

**Стек:** Java 21 · BigDecimal · Maven · JUnit 5 · GitHub Actions

## Возможности

- Сложение, вычитание, умножение и деление двух чисел.
- Положительные, отрицательные и дробные числа: `12.5` и `12,5`.
- Точная десятичная арифметика при сложении, вычитании и умножении.
- Деление с округлением до 10 знаков после запятой по правилу `HALF_UP`.
- Повторный ввод при ошибке; программа продолжает работу после деления на ноль.
- Просмотр и очистка истории текущего запуска.
- Выход через `q` на любом шаге; корректное завершение при конце ввода (EOF).
- Автоматические тесты и сборка исполняемого JAR.

## Пример работы

После стартовой справки:

```text
Операция (+, -, *, /) или h/help/c/q: +
Первое число: 0,1
Второе число: 0.2
Результат: 0.1 + 0.2 = 0.3

Операция (+, -, *, /) или h/help/c/q: /
Первое число: 1
Второе число: 3
Результат: 1 / 3 = 0.3333333333

Операция (+, -, *, /) или h/help/c/q: h
История вычислений:
1. 0.1 + 0.2 = 0.3
2. 1 / 3 = 0.3333333333

Операция (+, -, *, /) или h/help/c/q: q
До встречи!
```

## Запуск в IntelliJ IDEA

1. Распакуй архив в отдельную папку `java-console-calculator`.
2. В IntelliJ IDEA выбери **File → Open**, затем файл `pom.xml` в этой папке.
   Если IDE предложит выбор, открой его как проект (**Open as Project**).
3. Перейди в **File → Project Structure → Project** и выбери **JDK 21** в поле SDK.
   Если JDK ещё нет, используй **Download JDK** и установи версию 21,
   например Eclipse Temurin. Для проекта нужен JDK; версия самой IDEA — отдельная настройка.
4. Дождись импорта Maven. Если зависимости не подгрузились, нажми
   **Reload All Maven Projects** в окне Maven.
5. Открой `src/main/java/dev/portfolio/calculator/Main.java`.
6. Нажми зелёный треугольник рядом с `main` и выбери **Run 'Main.main()'**.
7. В окне **Run** введи операцию, нажми Enter, затем введи каждое число отдельной строкой.

**Тесты в IDE:** нажми правой кнопкой на `src/test/java` → **Run 'All Tests'**.
Альтернатива: в окне Maven запусти **Lifecycle → test**.

Отдельная установка Maven для работы через IDEA не нужна, если в настройках
Maven выбрана встроенная версия (**Bundled**). Для первого импорта нужен интернет,
чтобы получить зависимости тестов и плагины сборки.

## Запуск из терминала

Для этих команд нужны **JDK 21** и **Maven 3.9+**, доступные в `PATH`.
Запускай команды из папки с `pom.xml`.

```bash
java -version
mvn -version
mvn clean verify
java -jar target/java-console-calculator-1.0.0.jar
```

`mvn clean verify` запускает тесты и собирает JAR. Только тесты:

```bash
mvn test
```

После сборки самому приложению достаточно Java 21 или новее; внешние библиотеки
при запуске ему не нужны. JUnit используется только для тестирования.

## Команды и правила ввода

| Команда | Действие |
| --- | --- |
| `+` | Сложить два числа |
| `-` | Вычесть второе число из первого |
| `*` | Умножить два числа |
| `/` | Разделить первое число на второе |
| `h` | Показать историю |
| `c` | Очистить историю |
| `help` | Показать справку |
| `q` | Выйти на любом шаге |

Команды `h`, `c`, `help` доступны при выборе операции. Буквенные команды
не зависят от регистра. Пробелы по краям ввода удаляются.

- Вводи обычные десятичные числа без разделителей тысяч: `-12,5`, `+7`, `.5`.
- `1,234` означает дробь `1.234`. Записи `1 234`, `1e5`, `NaN` не поддерживаются.
- Результаты выводятся с точкой; ненужные нули после дробной части убираются.
- За один расчёт обрабатываются два числа и одна операция. Строки вида
  `2 + 3 * 4` и скобки не разбираются.
- Деление округляется даже для очень маленьких результатов:
  `1 / 100000000000` отображается как `0` при выбранной точности.
- История существует только в памяти и исчезает после выхода.

## Устройство проекта

Классы находятся в пакете `dev.portfolio.calculator`.

| Файл | Ответственность |
| --- | --- |
| `src/main/java/dev/portfolio/calculator/Main.java` | Запуск и создание объектов |
| `src/main/java/dev/portfolio/calculator/Calculator.java` | Арифметика и проверка деления на ноль |
| `src/main/java/dev/portfolio/calculator/Operation.java` | Перечисление четырёх операций |
| `src/main/java/dev/portfolio/calculator/DecimalNumbers.java` | Разбор и форматирование чисел |
| `src/main/java/dev/portfolio/calculator/ConsoleCalculator.java` | Консольный диалог и история |
| `src/test/java/dev/portfolio/calculator/` | Тесты вычислений, ввода и диалога |
| `pom.xml` | Версии Java, зависимостей и плагинов Maven |
| `.github/workflows/ci.yml` | Тесты и сборка при push и pull request |

`Calculator` не читает `System.in` и не печатает в `System.out`.
Это позволяет тестировать вычисления отдельно от интерфейса.
В тестах консоли вместо клавиатуры используется заранее подготовленный ввод.

## Что проверяют тесты

- Четыре операции с целыми, отрицательными и дробными числами.
- Точный результат `0.1 + 0.2`, округление деления и разные записи нуля.
- Точку, запятую, пробелы по краям и неверные значения.
- Несколько вычислений подряд, порядок истории и её очистку.
- Продолжение работы после ошибок, выход и EOF на разных шагах ввода.

GitHub Actions запускает `mvn clean verify` на Java 21 при каждом push
и pull request. Результат появится во вкладке **Actions** после загрузки проекта.
